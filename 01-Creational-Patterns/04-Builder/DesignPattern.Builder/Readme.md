# Builder Pattern Demo

This project demonstrates the **Builder** design pattern with several small examples:

- Computer
- Car
- Pizza
- Email

Each console app shows how Builder helps construct a complex object step by step.

## Project structure

- `01.Builder.Computer/`
- `02.Builder.Car/`
- `03.Builder.Pizza/`
- `04.Builder.Email/`
- `05.Builder.Order/`
- `06.Builder.VirtualMachine/`

## Run

Open the solution and run any console project, or use:

```bash
dotnet run --project 01.Builder.Computer/01.Builder.Computer.csproj
```

## Learning outcome

You will see how Builder improves readability when an object needs many optional settings.
