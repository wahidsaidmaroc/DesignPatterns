# Patterns comportementaux

Chaque dossier contient une petite application console .NET 10, un exemple exécutable et un exercice guidé en français.

| Pattern | Exemple |
|---|---|
| Chain of Responsibility | Faire approuver une dépense |
| Command | Commander une lampe avec annulation |
| Interpreter | Évaluer une addition |
| Iterator | Parcourir une collection de livres |
| Mediator | Échanger des messages dans une salle de discussion |
| Memento | Annuler les modifications d'un texte |
| Observer | Diffuser les changements météo |
| State | Gérer les états d'une commande |
| Strategy | Choisir un mode de livraison |
| Template Method | Générer des rapports CSV et texte |
| Visitor | Calculer le prix de formes géométriques |

Ouvrir le README de chaque pattern pour suivre l'exercice et exécuter son projet.
