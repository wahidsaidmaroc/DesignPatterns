# Interpreter — addition

Interpreter représente une expression par des objets qui savent l'évaluer selon une petite grammaire.

## Étapes de l'exercice

1. Repérez les expressions terminales (`NumberExpression`) et non terminales (`AddExpression`).
2. Lisez l'arbre qui représente `3 + (4 + 2)`.
3. Exécutez le programme et vérifiez le résultat.
4. Ajoutez une expression de soustraction.
5. Construisez une expression imbriquée qui utilise l'addition et la soustraction.

## Exécution

Depuis ce dossier : `dotnet run --project InterpreterDemo.csproj`.
