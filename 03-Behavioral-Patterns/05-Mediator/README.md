# Mediator — salle de discussion

Mediator centralise les échanges entre membres pour éviter qu'ils soient directement couplés.

## Étapes de l'exercice

1. Repérez le médiateur `ChatRoom` et les participants `ChatMember`.
2. Observez que les membres envoient leurs messages à la salle, pas les uns aux autres.
3. Exécutez les deux échanges du programme.
4. Ajoutez un troisième membre et inscrivez-le à la salle.
5. Ajoutez une méthode pour retirer un membre, puis vérifiez qu'il ne reçoit plus de messages.

## Exécution

Depuis ce dossier : `dotnet run --project MediatorDemo.csproj`.
