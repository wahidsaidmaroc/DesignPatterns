# Composite — menu

Composite permet de traiter un élément simple et un groupe d'éléments avec la même abstraction.

## Étapes de l'exercice

1. Repérez l'abstraction commune `MenuComponent`.
2. Comparez `MenuItem`, qui est une feuille, et `Menu`, qui contient des composants.
3. Exécutez le programme et observez l'affichage récursif du menu.
4. Ajoutez un nouvel élément et un sous-menu imbriqué.
5. Ajoutez une méthode commune, par exemple `CountItems`, et faites-la fonctionner sur un menu complet.

## Exécution

Depuis ce dossier : `dotnet run --project CompositeDemo.csproj`.
