# Patterns structurels

Chaque dossier contient une petite application console .NET 10, un exemple exécutable et un exercice guidé en français.

| Pattern | Exemple |
|---|---|
| Adapter | Adapter un ancien service de paiement |
| Bridge | Envoyer des messages par e-mail ou SMS |
| Composite | Composer un menu avec des sous-menus |
| Decorator | Ajouter des options à un café |
| Facade | Piloter un système de cinéma maison |
| Flyweight | Partager les styles de caractères d'un document |
| Proxy | Charger une image à la demande |

Ouvrir le README de chaque pattern pour suivre l'exercice et exécuter son projet.
